# GameController

This was the GameController software for robot soccer games in the [RoboCup](https://robocup.org) [Standard Platform League](https://spl.robocup.org) until 2025.

From 2026 on, the Standard Platform League is superseded by the [Humanoid Soccer League](https://hsl.robocup.org), which uses [this GameController](https://github.com/RoboCup-HumanoidSoccerLeague/GameController).
